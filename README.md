## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies `entry.png` to the output directory. `draw.py` is the script that drew `entry.png` from the day's headlines (Pillow, local use only — the grader runs `main.py` with the standard library alone and no network).
